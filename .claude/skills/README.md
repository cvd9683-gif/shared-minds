# Design skills for this repo

Claude Code loads these automatically when it works in `shared-minds`. They are
copied, unchanged, from their open-source repositories (licences kept in each folder).

| Skill | Use it for | Source |
|---|---|---|
| `impeccable` | Design direction, PRODUCT.md / DESIGN.md, critique, typeset, layout, animate, polish, audit | [pbakaus/impeccable](https://github.com/pbakaus/impeccable) @ 508d7e8 · Apache-2.0 |
| `taste-skill` (`design-taste-frontend`), `redesign-skill` | Committing to a strong visual direction; avoiding generic AI-looking UI | [Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill) @ ce26fc2 · MIT |
| `emil-design-eng`, `animate`, `improve-animations`, `review-animations`, `animation-vocabulary`, `find-animation-opportunities`, `apple-design`, `break-ui`, `prototype` | Motion, easing, springs, interaction craft | [emilkowalski/skills](https://github.com/emilkowalski/skills) @ e8a175d · MIT |
| `web-design-guidelines` | Final audit: accessibility, focus, forms, responsive, copy | [vercel-labs/agent-skills](https://github.com/vercel-labs/agent-skills) @ 063bee9 · MIT |

Suggested order for a design pass: direction (impeccable / taste) → build → motion
(emil) → audit (web-design-guidelines). To update a skill, copy the newer folder over it.
