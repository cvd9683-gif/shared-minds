# Shared Minds

Weekly assignments for ITP's Shared Minds class. Cathy Doss.

The index page is [`index.html`](index.html) — open it in a browser, or serve the folder
with `python3 -m http.server`.

---

## Week 1 — Thought Forest

Type a thought and it takes root. Each one becomes a small procedural tree that grows into
a swaying forest, so a stream of consciousness ends up as something you can stand in and
look at. An **Overwhelm** slider drives how hard the whole forest moves.

**[Open the forest](https://cvd9683-gif.github.io/shared-minds-thought-forest/)**
· [Source](https://github.com/cvd9683-gif/shared-minds-thought-forest)

## Week 2 — Learning the Steps, Feeling the Dance

Take turns with a dancer. You teach it a phrase of four to eight moves using the arrow keys
and the space bar, in whatever rhythm you like; it answers with a phrase of its own. A
language model makes that answer from nothing but your move names and the millisecond gaps
between them — it never sees the figure, or you — and both phrases are drawn at the same
scale so one can be read against the other.

**[Source](https://github.com/cvd9683-gif/shared-minds-learning-the-steps)**

Runs locally with `npm start`. The dancer's own turn needs a Replicate API key; teaching and
replaying your phrase work without one.
